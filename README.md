# Lab-3-Responsive-Portfolio
## Description
A responsive personal portfolio website created using HTML and advanced CSS concepts.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- CSS Animations
- CSS Transitions
- CSS Transforms

## Features
- Header and Navigation Bar
- Hero Section with Profile Picture
- About Me Section
- Skills Section
- Projects Section
- Contact Form
- Footer
- Responsive Design

## Responsive Behavior
The website is tested using the following breakpoints:

- Desktop: Above 768px
- Tablet: Up to 768px
- Mobile: Up to 480px

## CSS Concepts Implemented
- Flexbox for alignment and layout
- CSS Grid for Skills and Projects
- Relative Units (rem, %, vw, vh)
- Hover Effects
- Keyframe Animations
- CSS Transitions and Transforms
